# Ukázkové výstupy

Jeden až dva hotové dokumenty, které značku drží správně — schválené tím,
kdo ji hlídá. Podle nich se pozná, co je „správně", líp než podle pravidel.

Doporučený obsah:

- `report.html` — jednostránkový report v HTML s `tokens.css`
- `report.pdf` — totéž vytištěné do PDF (návod 12 pluginu školení)

Skill se značkou na tyhle soubory odkazuje jako na vzor: „vyrob to jako
`examples/report.html`, jen s jiným obsahem". To je nejkratší cesta ke
konzistentnímu výstupu.
